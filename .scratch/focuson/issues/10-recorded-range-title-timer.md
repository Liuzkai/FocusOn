# 10: 记录范围时间轴与标题计时

**What to build:** 用户要求时间轴默认铺满当天已有记录范围，随记录增长；可切换 24h。首行添加标题计时的开始、暂停/继续、停止；三行改为“使用 / 停止 / 计时”。

**Blocked by:** 09（closed）

**Status:** ready-for-agent

## Acceptance criteria

- 默认记录范围排除头尾采集缺口；实时自动增长。24h 使用真实本地日边界，缩放/平移后保持视窗，可重置所选模式。
- 首行输入标题开始一个计时，开始后显示累计时间、暂停/继续和停止；停止保留历史。标题计时不改变前台记录或软件汇总。
- 三行使用/停止/计时，未记录在使用行用斜纹保留。计时可与使用/停止并行，并参与搜索、详情和范围筛选。
- SQLite 保存计时和片段；跨日裁切，重启恢复为暂停，不补算程序未运行的时间；按天删除包括计时，保留其他日期且不复活已删时间。
- 默认锁屏继续计时，睡眠和退出暂停，手动继续；如用户回复另有偏好则以回复为准。识别时钟异常，不补算异常尾段。
- Release 构建、核心集成回归、WPF 离屏预览、代码审查和提交；真实桌面交互及锁屏/睡眠分项交 08。
