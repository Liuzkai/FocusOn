# 02: 暂停及系统停止时不计时，并在全部条件解除后恢复

**What to build:** 用户可在主窗口暂停和继续；锁屏、睡眠、会话灭屏自动停止计时。基本日志与状态显示停止原因，恢复只在全部条件满足后从实际前台窗口重新开始。

**Blocked by:** 01：记录真实前台使用片段，并显示今天日志与软件汇总

**Status:** closed

## Acceptance criteria

- [x] 主窗口提供可键盘操作的暂停/继续；手动暂停立即结束使用片段，同一采集会话内只能由用户主动继续清除，解锁、唤醒或亮屏不能代替继续。
- [x] 真实 Windows 锁屏、睡眠与会话灭屏结束使用片段并保存停止计时区间；无输入不触发这些停止条件，仅关闭多屏中的一台不直接视为整个会话灭屏。
- [x] 同时维护手动暂停、睡眠、锁屏、会话灭屏和采集可用状态；仅采集可用、未手动暂停、未睡眠、已解锁且会话屏幕已亮时恢复。一个恢复事件不能覆盖尚存的停止条件。
- [x] 停止原因重叠时依次以手动暂停、睡眠、锁屏、灭屏为主要原因；主要原因变化时分段并显示明确文字；全部停止计时区间不参加软件时长汇总。
- [x] 每次恢复主动读取实际前台窗口及系统状态，恢复后的时间不继续归给旧软件；启动时已经处于停止状态也遵守相同条件。
- [x] 经真实临时 SQLite 验证 T04、T05，包括手动暂停→锁屏→解锁、唤醒后仍锁屏和四种原因逐个解除。
- [x] 记录 W04 实机观察：锁屏、睡眠/唤醒、会话灭屏、多显示器与 Modern Standby。目标环境不支持的项目标注原因，不写成通过。
