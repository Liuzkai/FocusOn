# 09: 按用户截图调整 DeepSeek Harness 风格每日回看 UI

**What to build:** 用户于 2026-10-10 要求严格按所附 DeepSeek Harness 时间轴截图修改一版 UI。保留 FocusOn 记录语义，采用深色紧凑工具栏、固定三行时间总览、时段分隔和彩色软件标签日志；搜索及可开合详情与时间线联动。

**Blocked by:** 05：时间线、范围筛选和联动详情（closed）

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 深色背景、低对比分隔线、顶栏选中态与右侧搜索框；取消大标题、表格列头和常驻侧栏，日志采用截图中的单行标签结构。
- [ ] 时间总览固定三行“使用 / 停止 / 未记录”，软件颜色与日志/汇总一致；保留真实时长比例及已有半开区间契约，不按参考源码的最小像素宽度人为放大短片段。
- [ ] 顶栏“时长”开合总览，“时段”开合小时分隔，“详情”开合选中记录侧栏；详情显示完整标题和精确时间。
- [ ] 当前所选日期的软件/标题搜索立即筛选日志、淡化不匹配时间条，全天汇总不变；点击被筛掉的时间条可以清除筛选并定位日志。
- [ ] 原有拖选、键盘选择、日期、暂停、删除和虚拟化仍可用；增加滚轮缩放、右键清除范围及缩放后的右键平移。系统高对比度使用系统色，实时刷新保持现有选择与位置。
- [ ] Release 构建、完整回归及 WPF 合成数据离屏渲染通过；记录证据边界。真实鼠标/键盘、电源、DPI、高对比度检查由 08 继续，未执行不记通过。
- [ ] 完成 Standards / Spec 审查和本地提交，生成对应源提交的新 x64 自包含包。
