# 05: 通过比例时间线、范围筛选和联动详情回看一天

**What to build:** 在每日汇总下方显示横向使用时间线，与时间顺序日志和详情联动；用户可以拖选范围、缩放、悬停、点击或用键盘检查记录，全天汇总保持不变。

**Blocked by:** 02：暂停及系统停止时不计时，并在全部条件解除后恢复；04：按日期回看历史，并让跨午夜片段与全天汇总一致

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 页面依次呈现日期/记录状态、全天软件汇总、横向时间线、时间顺序日志及详情；直接使用每日查询结果，不另建计时或软件汇总逻辑。
- [ ] 区段宽度按真实持续时间比例绘制，同一软件颜色固定；两秒片段不人为扩宽计时宽度，可通过缩放查看。支持放大、缩小及恢复全天。
- [ ] 停止计时区间以灰色和明确原因文字呈现，未记录以不同纹理及文字呈现；已知停止、采集空缺与没有可用记录互不混淆。
- [ ] 当前片段标注进行中并持续延长；悬停显示软件名、精确起止和时长，选中详情显示完整标题及更精细时长；日志时刻显示到秒，取整不改变底层统计。
- [ ] 时间线和日志双向选择、定位同一记录；缩放、日期切换或数据刷新后不会选择错误记录。
- [ ] 拖选范围仅筛选每日投影中有实际相交部分的日志，仅接触结束边界不算相交；日志起止仍为当日投影，不再次按选择范围裁短；全天汇总不变，筛选范围明确可见并可恢复。
- [ ] 日期、日志选择、详情和缩放可用键盘完成，状态信息不只依赖颜色；日志虚拟化，不因长期历史创建全部界面行。
- [ ] 真实 SQLite + 公开每日查询验证 T09；实机记录 W07、W08，包括窄片段、拖选边界、联动、日期/缩放/刷新、无鼠标主要操作及文字表达。
