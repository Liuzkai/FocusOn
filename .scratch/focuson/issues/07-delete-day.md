# 07: 按天确认删除，保留其他日期并继续记录未来活动

**What to build:** 用户在日期回看中确认删除该日；其他日期尤其跨午夜的另一日保持可用。删除今天后继续记录未来活动，已删片段与标题不会通过检查点或重启重新出现。

**Blocked by:** 03：异常停止或保存失败后只展示可信记录，并明确缺口；04：按日期回看历史，并让跨午夜片段与全天汇总一致

**Status:** closed

## Acceptance criteria

- [x] 删除前显示目标本地日期及范围并要求用户确认；取消不改数据，操作可用键盘完成；只删除选定一天，不增加多日批量删除或撤销恢复。
- [x] 事务删除该日范围，包括使用片段、停止计时和未记录范围；跨日记录只删除当日部分，其他日期投影和汇总保持正确。
- [x] 删除成功后的范围显示没有可用记录，不显示为采集故障、不自动补回；重开数据库仍遵守删除结果。
- [x] 删除今天时先结束开放片段，串行完成删除，再从删除完成后的新时刻记录未来状态；后续检查点、标题变化、切换和重启都不回写已删使用/标题。
- [x] 删除不清除手动暂停或睡眠、锁屏、灭屏条件；只有全部恢复条件满足才恢复软件计时，暂停期间删除后仍保持暂停。
- [x] 删除失败保留此前成功数据并提示失败，不把操作报告为成功，不开始可复活旧内容的并发保存流程。
- [x] 真实临时 SQLite 验证 T10、T11，包含历史日、跨日、正在采集的今天、停止状态下删除、后续保存和重启；公开日志、软件汇总及范围类型一致。
- [ ] 完成 W09 实机验证日期/范围确认、连续采集下删除和跨日保留，记录删除后再次切换、检查点与重启的观察结果。
