# 04: 按日期回看历史，并让跨午夜片段与全天汇总一致

**What to build:** 用户默认回看今天，也可选择历史日期；跨午夜片段在每日日志中只显示当天部分，软件全天汇总使用同一投影，当前日期的进行中记录持续更新。

**Blocked by:** 01：记录真实前台使用片段，并显示今天日志与软件汇总

**Status:** closed

## Acceptance criteria

- [x] 提供有键盘操作的日期选择，默认今天；每日查询统一提供使用片段、已有停止计时区间、未记录范围、全天汇总和当前状态，界面不自行实现第二套裁切或汇总。
- [x] 正常时间与时区条件下按本地日期边界裁切 UTC 保存区间；每日日志显示该日部分起止与时长，软件汇总只合计使用片段的同一裁切结果。
- [x] 跨午夜前台片段在两日视图分配正确；现有未记录类型和后续 02 引入的停止计时类型复用同一按日投影，不混入软件汇总。04 不等待 02 的采集入口，完整停止类型跨日回归纳入整体验证。
- [x] 今日进行中片段可实时延长；过去日期不出现今天的进行中尾段。视图日期不会修改原始历史或计时归属。
- [x] 没有可用数据时明确说明；保留长期历史，不添加自动清理、搜索或导出。
- [x] 在同一公开记录会话边界通过真实临时 SQLite 验证 T08：23:59–次日00:01，两天各一分钟，日志投影与软件汇总一致；日期边界半开，不重复累计。
