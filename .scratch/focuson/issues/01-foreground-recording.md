# 01: 记录真实前台使用片段，并显示今天日志与软件汇总

**What to build:** 启动 FocusOn 后，真实前台窗口及其标题变化形成使用片段并保存到本机；主窗口显示今天的时间顺序日志、软件累计前台使用时长和当前采集状态。第一票同时完成可构建的最小桌面程序，后续票在这条真实路径上扩展。

**Blocked by:** None (can start immediately)

**Status:** closed

## Acceptance criteria

- [ ] 准备并记录匹配的开发 SDK 和构建命令；采用既定 C#、.NET 10、WPF、Microsoft.Data.Sqlite，一个生产项目和一个进程，不加入 ORM、服务端或通用框架。WinForms 托盘交互在 06 接入，不提前实现。
- [ ] 启动主动读取当前前台窗口；捕获实际前台窗口切换和当前前台窗口标题变化。不同窗口即使软件与标题相同也分段；重复相同观测和后台标题变化不分段；两秒切换保留。
- [ ] 每段有稳定记录标识、采集顺序、软件身份/名称、完整窗口标题、起止时刻和持续时长；稳定软件身份用于合并汇总，PID/窗口句柄不作为跨启动的软件标识。
- [ ] 同一时刻只有一个前台窗口累计时长；后台播放及其他可见窗口不计，FocusOn 自身遵循相同规则；无键鼠输入仍继续计时，不采集输入内容。
- [ ] 确认窗口但身份失败显示未知软件；空标题或标题读取失败显示标题不可用，均保留可信时长；无法确认前台的范围显示未记录；权限受限及打包应用无法解析时不猜测宿主为实际软件。
- [ ] 保存 UTC 起止时刻，并以单调时间累计持续时长；正常时间/时区条件下采用半开区间，切换无重叠、空片段或重复累计。
- [ ] 数据在当前 Windows 用户本地应用数据目录的真实 SQLite 长期保存，不自动清理。实现低频检查点（初始建议五秒）及切换时事务保存，基础界面不将未落盘尾段声称为已保存。
- [ ] 以统一的时间区间查询结果显示今天基本日志、软件汇总按累计时长降序和记录状态；重新打开数据可回看成功保存片段。该票演示正常单日采集，后续区间类型沿用同一结果契约，完整异常恢复与跨日回看分别由 03、04 补齐。
- [ ] 全程可断网工作，只采集软件/标题/时间元信息，不另行采集截图、正文、地址栏网址或键盘内容；标题本身含网址不额外解析地址。
- [ ] 在记录会话这一公开行为边界输入可控观测与时间，经过真实临时 SQLite 验证 T01、T02、T03、T06；记录 W01–W03 实机结果、事件遗漏/补查及应用识别限制，不用假事件通过代替真实采集验证。
