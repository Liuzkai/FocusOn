# 06: 登录自启、驻留托盘，并保持单实例记录

**What to build:** 程序登录后驻留托盘采集；关闭主窗口继续记录；托盘能打开回看、暂停、继续或退出；重复启动定位已有实例，明确退出保存并停止。

**Blocked by:** 03：异常停止或保存失败后只展示可信记录，并明确缺口

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 在当前 Windows 用户登录时从固定程序位置启动并开始采集，不安装独立服务；自启延迟或程序未运行范围属于未记录，不补造登录后的活动。
- [ ] 关闭主窗口隐藏到托盘，采集不中断；托盘打开主窗口、暂停、继续、退出调用同一记录会话，暂停/继续遵守全部停止条件并反馈实际状态。
- [ ] 单实例运行，重复启动显示/定位已有实例，不产生第二个采集写入者或重复时间；主窗口隐藏时也可定位。
- [ ] 明确退出保存当前可信终点并停止采集，移除托盘；若保存失败显示可靠性结果，不把失败终点称为成功保存；下次启动不补造退出期间活动。
- [ ] 启动/恢复正确注册并保持 Windows 消息循环与观测生命周期；重开主窗口不会重复订阅而产生重复片段。
- [ ] 完成 W05 实机验收并记录自启配置、登录、自启延迟、关窗持续采集、托盘操作、重复启动和退出/再启动结果。
