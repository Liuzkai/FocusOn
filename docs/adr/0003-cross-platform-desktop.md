# ADR 0003：跨平台桌面与采集权限

日期：2026-10-11。状态：采用（用户要求 Windows、Linux、macOS）。

用户的新要求扩展了原先只支持 Windows 的产品边界。统一使用 .NET 10 / Avalonia 桌面界面，将原记录会话、SQLite 和每日投影放入无桌面依赖的核心项目；不改变前台使用时长、标题计时或旧数据库口径。系统接口放入平台项目，权限与采集能力必须在界面显示。

- Windows 保留 WinEvent 前台/标题事件与 WTS/电源通知。
- Linux X11 读取 EWMH 当前激活窗口、UTF-8 标题和进程身份。Wayland 禁止普通应用任意枚举其他窗口；GNOME 使用仓库随附的用户启用扩展桥接，不读取 XWayland 窗口假装覆盖原生 Wayland。未提供桥接的桌面仍可使用标题计时和回看，但前台记录明确标为不可用。
- macOS 使用 NSWorkspace 当前应用与辅助功能窗口接口。需要用户授予辅助功能权限；不申请屏幕录制，不读取窗口内容。系统睡眠、会话和屏幕状态通过原生接口观测。
- 各平台使用当前用户的数据目录和自启机制。重复启动以数据目录锁和当前用户命名管道激活已有实例。隔离 `--data-dir` 模式不注册自启。
- Unix 平台采样间隔为 200ms，保证通常能保留两秒切换，但不承诺重建两个采样间的全部事件。采样停顿或恢复异常保留未记录范围，并暂停标题计时，不能将睡眠归给旧软件。
- 桌面环境不提供托盘时关闭窗口提示并保留恢复入口；完整操作验收仍须对应操作系统，跨平台编译不代表原生接口已验收。
