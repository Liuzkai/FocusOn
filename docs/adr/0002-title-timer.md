# ADR 0002: 独立标题计时与可信保存

日期：2026-10-10。状态：采用；锁屏行为为未收到偏好回复时选择的默认规则，可按用户后续要求调整。

用户要求首行输入标题并主动计时，提供暂停和停止，时间轴增加计时行。沿用 ADR 0001 的前台口径，将标题计时独立保存，避免软件汇总重复累计。

- 一次一项未停止计时，开始/继续形成片段，暂停保留累计时长，停止保留历史并可开始新标题。标题限 200 字。
- 暂停软件记录、锁屏和灭屏不改变标题计时；睡眠通知和正常退出将其暂停，恢复后手动继续。关窗隐藏到托盘仍计时。它不是注意力度量。
- 运行期间使用单调时长和 UTC 起止，检查点保存可信终点；实时查询不会写入。时间或时区跳变时暂停并提示，不补算异常尾段。
- SQLite 新增 title_timers、timer_segments，与前台记录共享串行工作线程和连接。未停止项重启后恢复为暂停，只认可成功保存的片段，不补算停机时间。原库按 CREATE IF NOT EXISTS 扩展。
- 每日裁切采用真实本地日边界、半开区间和原始时长分配基准。标题历史与软件使用可同时存在，在同一每日视图中展示，软件汇总只包含 Usage。
- 按天删除同时事务删除两种历史，保留其他日期；影响进行中标题片段时先暂停，删除后需手动继续。未停止标题仍保留为暂停项以便继续，累计时长只包含保留下来的片段。已停止且无剩余片段的标题元信息一并清除。
