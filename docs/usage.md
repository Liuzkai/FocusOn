# FocusOn 使用说明

FocusOn 记录当前 Windows 用户的软件前台使用过程，适用于 Windows 11 x64。完整交付文件夹包含运行时，使用程序不需要 .NET SDK、开发工具或网络。

## 开始使用

1. 将完整交付文件夹解压到固定位置，例如 `C:\Apps\FocusOn`；不要只复制 `FocusOn.exe`。
2. 双击 `FocusOn.exe`，开始采集并打开今日回看。普通启动会自动配置当前用户登录自启，指向这个固定程序路径；以后登录 Windows 时隐藏启动到托盘。
3. 关闭主窗口会隐藏到托盘，继续记录。托盘可打开回看、暂停、继续和退出。重复启动同一数据目录的程序会定位已有实例。

需要结束采集时使用托盘的“退出”。移动交付目录前先退出，再从新位置普通启动以更新自启路径。程序没有安装器、自动更新器或应用内自启开关；普通启动设置的是当前用户 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 中的 `FocusOn` 值。

## 计时与回看

只有被激活的窗口累计前台使用时长；另一个可见窗口、后台音乐和后台视频不因此计时。没有键鼠输入仍计时，静读也会累计。FocusOn 自身同样记录。这些时长不能解释为实际注意力或真实工作时长。

手动暂停、锁屏、睡眠或整个会话灭屏时停止软件计时。主动暂停不会因解锁、唤醒或亮屏自动取消；只有停止条件全部解除才恢复。停止计时区间显示原因，采集工具未运行或故障导致的范围显示为未记录，不推测补给旧软件。

- 默认显示今天；用日期控件、左右箭头（上一天/下一天）或今天按钮回看。顶部状态始终表示当前记录状态。
- 软件汇总按全天前台使用时长排序。时间线按真实时间比例绘制；极短片段可先在日志选中再放大。
- 点击时间线或日志查看对应记录，详情显示完整标题与精确时间；悬停时间线显示起止和时长。
- 时间轴默认“记录范围”：从当天首条可确认的记录到最新终点，随记录增长；头尾未记录缺口在“24h”模式查看。24h 表示本地全天，夏令时日期按真实日边界显示。“重置视图”恢复当前模式并清除范围；缩放或平移后刷新保持视窗。
- 三行时间总览显示使用、停止、计时；未记录在使用行以斜纹表示。彩色软件标签与全天汇总使用相同配色，蓝色计时片段表示独立标题计时。“时长”开合总览，“时段”开合小时分隔，“详情”开合侧栏；点击记录自动打开详情。
- 顶部搜索限定所选日期的软件名、状态文字及窗口标题，筛选日志并淡化不匹配时间条，不影响全天汇总。清空恢复当前范围的日志；点击被筛掉的时间条时清除排除它的搜索/范围，并定位该记录。
- 拖选范围只筛选相交日志，不裁短日志、不改变全天汇总。“取消范围”或右键单击取消范围，仍保留搜索。加减按钮或滚轮缩放，缩放后可右键拖动平移；选中记录范围之外的未记录日志会切换 24h，以便显示该记录。
- 主要控件可用 Tab 和 Enter/Space 操作；时间线可用方向键选择、Shift＋方向键选择范围、加减键缩放、Escape 取消范围。日志和详情提供文字信息。

## 数据与删除

首行填写计时标题（最多 200 字），点击“开始计时”；随后显示累计时间、“暂停”和“停止”。暂停后点击“继续”接着累计，停止后保存历史并可填写新标题，一次只能有一个未停止计时。计时记录可搜索标题、拖选或查看详情，不加入软件使用汇总。“暂停记录”只控制软件采集。

标题计时锁屏或灭屏时继续；睡眠、退出软件或系统时间/时区异常时暂停，之后手动继续。关闭窗口仍在托盘计时。重开程序恢复为暂停，仅保留已成功保存的时间，不补算程序未运行的时间。

正式数据保存在 `%LOCALAPPDATA%\FocusOn\focuson.db`。运行时可能还有 SQLite 的 `focuson.db-wal` 和 `focuson.db-shm` 文件。记录长期保留，不自动清理。

程序保存软件身份、名称、窗口标题、起止时间和持续时长，不采集截图、正文、键盘输入，也不另行读取浏览器网址。**窗口标题本身可能包含文档名、网页名、网址或其他私人信息。** 数据留在当前用户本机，不提供云同步。

选择日期后使用“删除当天…”，先核对确认框日期及范围。取消保留原数据；确认仅删除所选日，跨午夜记录的其他日部分保留。删除后没有可用记录的范围保持空白。删除今天后，从删除完成之后继续记录未来活动；处于暂停时仍保持暂停。删除没有撤销或恢复功能。

按天删除也删除当日标题计时片段；影响正在运行的标题计时时先暂停，需手动继续。未停止标题保留为可继续的暂停项，其累计时间随删除扣除；已停止且没有剩余片段的标题也会清除。

## 保存边界与限制

进行中的实时显示会继续增长，但尾段可能尚未保存。程序约每五秒保存检查点，窗口切换、停止计时和正常退出时保存边界；崩溃或断电可能丢失未保存尾段，正常调度下约为五秒内。重启只认可成功保存的范围，之后的缺口显示未记录。

看到记录异常或保存失败提示时，先检查数据目录是否可写、存储是否可用；不要把实时增长当作保存成功。退出也可能报告最后一段保存失败。

Windows 窗口/标题通知可能遗漏或延迟，五秒补查只能校核当时状态，不能完整还原漏失活动。权限受限或无法解析的打包应用可能显示未知软件或标题不可用。不同硬件的电源/Modern Standby 行为仍需实机核验；手动改时钟或切换时区后的历史时间映射不属于第一版正确性承诺。

## 隔离验收

人工验收使用独立数据目录，避免改变正式活动记录：

```powershell
$qaData = Join-Path $env:LOCALAPPDATA 'FocusOn-QA\data'
& 'C:\Apps\FocusOn\FocusOn.exe' --data-dir $qaData
```

此入口不设置正式登录自启。需要验证隐藏启动时使用固定顺序 `--startup --data-dir <测试目录>`。完整步骤见仓库中的 `docs/manual-acceptance.md`；未做的硬件或界面检查不能从逻辑测试推断通过。
