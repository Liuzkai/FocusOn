# FocusOn 使用说明

FocusOn 记录 Windows、Linux、macOS 当前用户的软件前台使用过程。平台依赖和授权见[平台说明](platforms.md)。完整交付文件夹包含运行时，使用程序不需要 .NET SDK、开发工具或网络。

## 开始使用

1. 将对应系统和架构的完整交付解压到固定位置：Windows 运行 `FocusOn.exe`，Linux 运行 `./FocusOn`，macOS 打开完整 `FocusOn.app`。
2. 启动当前平台程序，开始采集并打开今日回看。普通启动遵循配置页的登录自启选择（默认启用），指向固定程序路径；登录启动时只有确认托盘可用才隐藏窗口，无可用托盘则保留窗口。
3. Windows/Linux/macOS 关闭主窗口时，确认托盘/菜单栏可用则隐藏并继续记录和计时；托盘不可用时保持可见窗口，Linux 宿主消失时恢复隐藏窗口。托盘提供打开、暂停、继续、明确退出。重复启动同目录定位已有实例，Mac Dock 点击也可恢复。

需要结束采集时使用窗口或托盘的“退出”。移动交付目录前先退出，再从新位置普通启动以更新自启路径。v0.1.7 新增配置页、Windows 当前用户安装器和手动更新检查；自启开关保存在配置中，各平台入口见平台说明。macOS 辅助功能未授权、Wayland 桥接未启用或会话状态不可用时，前台采集显示不可用，仍可使用标题计时和历史回看。

## 计时与回看

只有被激活的窗口累计前台使用时长；另一个可见窗口、后台音乐和后台视频不因此计时。没有键鼠输入仍计时，静读也会累计。FocusOn 自身同样记录。这些时长不能解释为实际注意力或真实工作时长。

手动暂停、锁屏、睡眠或整个会话灭屏时停止软件计时。主动暂停不会因解锁、唤醒或亮屏自动取消；只有停止条件全部解除才恢复。停止计时区间显示原因，采集工具未运行或故障导致的范围显示为未记录，不推测补给旧软件。

- 默认显示今天；用日期控件、左右箭头（上一天/下一天）或今天按钮回看。顶部状态始终表示当前记录状态。
- 软件汇总按全天前台使用时长排序。时间线按真实时间比例绘制；极短片段可先在日志选中再放大。
- 点击时间线或日志查看对应记录，详情显示完整标题与精确时间；悬停时间线显示起止和时长。
- v0.1.2：时间轴提示跟随鼠标，跨段及重新悬停立即更新；拖动、移出、折叠时间轴或隐藏窗口时关闭。不同软件的连续区段之间有细小视觉间隙；间隙不改变时间、时长、点击和筛选的口径。
- v0.1.2：日志滚到最下方后持续跟随新增记录。向上滚动或选择历史记录暂停跟随；再次滚到底部恢复。首次打开长日志仍从原来的顶部显示，不抢走历史选择或修改全天汇总。
- v0.1.5 时间范围下拉选择 1h、2h、4h、6h、8h、12h、24h、今天，默认 1h。小时范围从当前快照向前取实际经过的小时数，可跨午夜；今天从本地 00:00 至现在，夏令时按真实日边界计算。历史日期以当天结束为参考，选择“今天”返回当前日期。“重置”恢复所选范围、清除选区并重新跟随实时终点；缩放或平移后刷新保持视窗。
- 三行时间总览显示使用、停止、计时；未记录在使用行以斜纹表示。彩色软件标签与全天汇总使用相同配色，蓝色计时片段表示独立标题计时。“时长”开合总览，“时段”开合小时分隔，“详情”开合侧栏；点击记录自动打开详情。
- 顶部搜索限定所选日期的软件名、状态文字及窗口标题，筛选日志并淡化不匹配时间条，不影响全天汇总。清空恢复当前范围的日志；点击被筛掉的时间条时清除排除它的搜索/范围，并定位该记录。
- 时间范围、缩放/平移视窗和拖选共同筛选相交日志，不额外裁短日志、不改变按日期选择器统计的全天汇总。跨日片段的每日投影按同一快照合并，日期显示在跨日时间轴和日志中；“今天”只读当前日期投影。“取消范围”或 Escape 取消拖选，仍保留视窗和搜索。加减按钮或滚轮缩放，右键拖动平移；拖选后右键单击放大到选区并保留筛选。左键单击选择记录。日期删除仅删除日期选择器指定的一天，不删除小时范围里其他日期的记录。
- v0.1.3：全天软件汇总的横向滚动条单独占一行，不覆盖软件标签。软件颜色优先与已分配颜色保持较大的感知差异，保存于所选数据目录的 `app-colors.json`；刷新、切日期、排序和重启沿用分配。不修改活动数据库或语言设置。偏好文件无法读取或写入时，保留原文件并使用本次进程内的颜色，不影响记录。软件很多时颜色仍可能接近，始终保留名称；高对比度模式使用系统对比色。
- v0.1.4：汇总区改为 3 DIP 细线，操作时显示，空闲约一秒后隐藏；底部仅预留 6 DIP，不覆盖标签、不改变布局。按住任意软件标签左右拖动即可横向滚动，也支持滚轮、横向触控板、左右键、Home/End/PageUp/PageDown；细线本身仍可拖动。拖动途中刷新保持位置；窗口隐藏、失去焦点或鼠标捕获丢失会清理拖动。汇总内容不足以溢出时不启动拖动或消耗滚动。
- 主要控件可用 Tab 和 Enter/Space 操作；时间线可用方向键选择、Shift＋方向键选择范围、加减键缩放、Escape 取消范围。日志和详情提供文字信息。

## 数据与删除

首行填写计时标题（最多 200 字），点击“开始计时”；随后显示累计时间、“暂停”和“停止”。暂停后点击“继续”接着累计，停止后保存历史并可填写新标题，一次只能有一个未停止计时。计时记录可搜索标题、拖选或查看详情，不加入软件使用汇总。“暂停记录”只控制软件采集。

标题计时锁屏或灭屏时继续；睡眠、退出软件或系统时间/时区异常时暂停，之后手动继续。关闭窗口仍在托盘计时。重开程序恢复为暂停，仅保留已成功保存的时间，不补算程序未运行的时间。

数据库文件名为 `focuson.db`。Windows 数据目录 `%LOCALAPPDATA%\FocusOn`；Linux 默认 `~/.local/share/FocusOn`（支持 `XDG_DATA_HOME`）；macOS 为 `~/Library/Application Support/FocusOn`。运行时可能还有 SQLite 的 `focuson.db-wal` 和 `focuson.db-shm` 文件。记录长期保留，不自动清理。

程序保存软件身份、名称、窗口标题、起止时间和持续时长，不采集截图、正文、键盘输入，也不另行读取浏览器网址。**窗口标题本身可能包含文档名、网页名、网址或其他私人信息。** 数据留在当前用户本机，不提供云同步。

选择日期后使用“删除所选日期”，先核对确认框日期及范围。取消保留原数据；确认仅删除所选日，跨午夜记录的其他日部分保留。删除后没有可用记录的范围保持空白。删除今天后，从删除完成之后继续记录未来活动；处于暂停时仍保持暂停。删除没有撤销或恢复功能。

按天删除也删除当日标题计时片段；影响正在运行的标题计时时先暂停，需手动继续。未停止标题保留为可继续的暂停项，其累计时间随删除扣除；已停止且没有剩余片段的标题也会清除。

## 保存边界与限制

进行中的实时显示会继续增长，但尾段可能尚未保存。程序约每五秒保存检查点，窗口切换、停止计时和正常退出时保存边界；崩溃或断电可能丢失未保存尾段，正常调度下约为五秒内。重启只认可成功保存的范围，之后的缺口显示未记录。

看到记录异常或保存失败提示时，先检查数据目录是否可写、存储是否可用；不要把实时增长当作保存成功。退出也可能报告最后一段保存失败。

Windows 窗口/标题通知可能遗漏或延迟，五秒补查只能校核当时状态，不能完整还原漏失活动。Linux/macOS 每 200ms 采样前台，较短切换可能遗漏；采样停顿超过两秒时不补算空缺，标题计时暂停，手动继续。权限受限或无法解析的打包应用可能显示未知软件或标题不可用。不同硬件的电源/Modern Standby 行为仍需实机核验；手动改时钟或切换时区后的历史时间映射不属于第一版正确性承诺。

## 隔离验收

人工验收使用独立数据目录，避免改变正式活动记录：

```powershell
$qaData = Join-Path $env:LOCALAPPDATA 'FocusOn-QA\data'
& 'C:\Apps\FocusOn\FocusOn.exe' --data-dir $qaData
```

此入口不设置正式登录自启。需要验证隐藏启动时使用固定顺序 `--startup --data-dir <测试目录>`。完整步骤见仓库中的 `docs/manual-acceptance.md`；未做的硬件或界面检查不能从逻辑测试推断通过。


## 统计页面（v0.1.6）

顶部“回看 / 统计”切换页面，语言、暂停记录和退出始终可用；切换不停止记录或标题计时，也不清除回看选中项和视窗。

“多日”默认近七天，可快速选近30天或填写包含首尾的起止日期，最多366天。空日期显示为零，平均每天以所选日数为分母。“单日时段”选择日期和本地 HH:mm 起止时间，24:00 表示当天结束；“全天”填写00:00–24:00。点击“应用筛选”后更新，图表上方始终注明实际已应用范围，输入错误保留上一份有效统计。未来时间不计入，重复夏令时小时在坐标和提示中显示UTC偏移。

环形图为软件时长占比（前五名及其他软件），柱状图为每日/实际小时桶的使用时长，折线为前三软件的趋势，下面列出完整软件明细。仅 Usage 参与，暂停、未记录和独立计时均排除。时段按原始单调时长分配基准裁切，不改写任何记录；总时长、软件合计和柱状分桶总和一致，已删除部分不恢复。

悬停图表查看实际时间与精确时长；Tab 聚焦图表后用左右/Home/End 切换项目，Escape 关闭提示。折线用不同线型区分，窄窗口纵向排列；高对比度和软件明细提供可读替代。打开统计时每五秒刷新一次，隐藏/切回回看停止统计刷新和提示；后台记录照常继续。

## 配置页面（v0.1.7 起；v0.1.8 更新文案）

- “配置”集中管理中文/English 与 Dark/Light，立即生效并保存；系统高对比度优先。切页不影响采集、独立计时和原有回看选中/视窗。
- “开机启动”（English: Start at login）默认启用，可关闭，选择立即保存；当前用户登录系统后自动启动，托盘可用时后台运行，否则显示窗口。隔离 `--data-dir` 模式不修改正式自启。系统托盘缺失时仍保留可恢复窗口。
- “数据保存”显示当前目录，可打开、输入完整新路径或通过系统选择目录，再点击“保存并重启”。目标必须为空，且与原目录不互相包含。确认后先保存、复制并校验 SQLite/配置，再重启；原目录保留为备份，独立计时暂停，不合并已有数据。失败仍使用原目录。正式默认目录内的 data-location.json 指向新的目录；隔离模式仅重启参数改变，不写正式指针。旧版不能识别新指针，勿运行旧版向备份写入后期待自动合并。备份前明确退出，并保留指针及其目标目录。
- “更新”仅点击时检查 GitHub 正式稳定版，不上传记录，不自动下载/安装。草稿不可更新；当前开发版本高于正式版时显示无可用更新。Windows 显式确认后下载并核对官方地址/大小/SHA256，再保存退出并启动安装器；其他系统从对应 Release 手动替换应用。Windows 安装器当前未签名，校验和不等于发行者签名。取消安装后手动重新打开应用。
- 最后的“关于”显示实际版本、进程平台架构、GitHub 地址和许可说明。更多安装说明见 [Windows](windows.md)。

## v0.1.8 页面名称

原“回看 / Review”页更名为“记录 / Records”，记录日期、列表更新提示同步改名；历史记录和计时行为不变。配置 → 启动与后台运行中的“开机启动”控制当前用户登录后启动。隔离测试模式仍显示开关，但禁用系统自启修改并注明原因。

## v0.1.9 检查更新限流修复

旧 v0.1.7/v0.1.8 显示 `403 (rate limit exceeded)` 时，需要先退出并手动安装一次官方修复包，原记录与配置保留。修复后 API 限流/服务故障/仅API连接超时可回退官方 Release，仍核对包地址、架构、准确大小、SHA256及校验文件，不要求 GitHub 令牌。成功检查短时缓存，限流请求退避；两条官方通道都失败时明确提示稍后重试或点击“查看 Release”手动下载，不冒称没有更新。草稿不会参与稳定更新检测；当前正式/latest 已按用户要求发布 v0.1.9。较新的开发版显示暂无正式更新仍是正常结果。


## v0.1.10 统计悬停交互

鼠标悬停时，环形扇区轻微浮起，柱条及其所在时间桶高亮，趋势点显示柔和光圈，统计卡片提亮并显示轻微阴影。过渡约170毫秒，结束后保持静态；离开图表会淡出强调，切页、隐藏窗口或退出立即清理提示和动画。图表空白区域也能显示所在时段的精确详情，统计数值与时长比例保持真实。

配置 → 外观中的“统计页面悬停动画”默认启用，选择立即保存；关闭后使用静态高亮，仍可悬停或用键盘查看详情。系统高对比度自动关闭动画，并保留已保存的选择。中英文切换刷新统计范围下拉框的可见文字，并保留当前时段、输入错误和已应用范围。此功能使用独立v0.1.10草稿，不替换已公开v0.1.9附件。
